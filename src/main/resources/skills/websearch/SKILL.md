# 联网搜索技能

## 能力范围
- 搜索互联网上的实时信息和最新资讯
- 适用场景：新闻动态、股票行情、政策法规、考试信息、赛事结果、产品资讯、百科知识、翻译等
- 底层使用百度搜索 API，返回最多 5 条相关结果（含标题、摘要、链接）

## 限制
- **不支持天气查询**：天气相关的问题应使用天气专用工具（weather）
- 搜索结果每条摘要最多 200 字，可能需要 AI 进一步整理和总结
- 搜索结果为中文内容为主

## 参数说明
| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| query | String | 搜索关键词，用简洁的自然语言描述 | "2026年杭州最新新闻" |

## 搜索策略
1. **提炼关键词**：从用户问题中提取核心搜索词，不要直接照搬整句话
    - ✅ "杭州 2026年7月 新闻"
    - ❌ "帮我看看今天杭州发生了什么事情"
2. **一次搜索不够时**：如果首次搜索结果不理想，可以换关键词再搜一次
3. **整理结果**：将搜索结果整理成结构化、易读的格式返回给用户，标注信息来源

## 使用示例

**示例 1：新闻查询**
用户："今天杭州有什么新闻"
→ search(query="杭州 今日新闻 2026")
→ 整理搜索结果，按重要性排列，每条包含标题和简要内容

**示例 2：股票查询**
用户："贵州茅台股票今天怎么样"
→ search(query="贵州茅台 股价 今日行情")
→ 提取关键数据（价格、涨跌幅），用简洁格式呈现

**示例 3：超出范围**
用户："杭州明天下雨吗"
→ 不应使用此工具，应使用天气专用工具

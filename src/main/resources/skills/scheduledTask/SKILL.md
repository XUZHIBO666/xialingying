# 定时任务技能

## 能力范围
- 创建一次性定时任务：在指定时间让 Bot 自动执行某个动作并发送结果给用户
- 查询当前所有活跃的定时任务
- 取消已创建的定时任务

## 限制
- **仅支持一次性定时任务**：不支持周期性重复任务（如"每天早上8点…"），周期任务需使用周期回复功能
- 最小粒度为分钟级，不支持秒级精度
- 任务执行的内容由 AI 在执行时动态生成，不是预设固定文本

## 工具方法

### 1. createTask — 创建定时任务
| 参数 | 类型 | 必填 | 说明 | 示例 |
|----|------|------|------|------|
| action | String | 是 | 要执行的动作描述 | "查询杭州天气并发送给我" |
| delayMinutes | Integer | 否 | 延迟分钟数（优先使用） | 5 表示5分钟后 |
| executeAt | String | 否 | 绝对执行时间（仅当 delayMinutes 无法表达时） | "2026-07-30T15:00:00" |
| repeat | String | 否 | 重复类型，目前仅支持 "once" | "once" |

**时间参数选择策略：**
1. **优先使用 delayMinutes**：用户说"X分钟后"时直接转换，避免手动计算日期出错
    - "5分钟后提醒我喝水" → delayMinutes=5
    - "半小时后…" → delayMinutes=30
    - "2小时后…" → delayMinutes=120
2. **仅在必要时用 executeAt**：用户明确说了具体日期时间
    - "明天下午3点提醒我开会" → executeAt="2026-07-31T15:00:00"
    - 注意：必须确认年份和日期正确，防止 AI 日期幻觉

### 2. listTasks — 查询活跃任务
无需参数，返回当前所有活跃定时任务列表。

### 3. cancelTask — 取消定时任务
| 参数 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| taskId | String | 是 | 要取消的任务ID | 从 listTasks 结果或 createTask 返回值获取 |

## 使用示例

**示例 1：延迟提醒**
用户："5分钟后提醒我喝水"
→ createTask(action="提醒用户喝水", delayMinutes=5)
→ 告知用户任务已创建及任务ID

**示例 2：指定时间执行**
用户："明天下午3点帮我查一下杭州天气"
→ createTask(action="查询杭州天气并发送给用户", executeAt="明天日期T15:00:00")
→ 注意：需根据当前日期计算"明天"的正确日期

**示例 3：查看任务**
用户："我有哪些定时任务"
→ listTasks()
→ 将任务列表整理后展示给用户

**示例 4：取消任务**
用户："取消刚才那个定时任务"
→ 先 listTasks() 确认任务ID，再 cancelTask(taskId="...")
→ 告知用户取消结果

**示例 5：超出范围**
用户："每天早上8点给我发天气预报"
→ 不属于此技能范围，应使用周期回复功能

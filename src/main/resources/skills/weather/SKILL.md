# 天气查询功能

## 能力范围
- 查询全球任意城市的天气
- 查询最多未来3天的天气(不包含3天)

## 限制
- wttr.in API 仅支持 3 天预报，不支持"下周"、"大后天"等超出范围的查询
- 遇到超出范围的请求，应告知用户限制并建议替代方案

## 参数说明

| 参数        | 说明                    | 示例         |
|:----------|:----------------------|:-----------|
| city      | 城市名（中文或英文）            | 杭州、Beijing |
| dayOffset | 天数偏移：0=今天, 1=明天, 2=后天 | 0          |

## 返回字段
- temperature: 温度（℃）
- humidity: 湿度（%）
- windSpeed: 风速
- description: 天气描述
- weather: 天气数组（含 main、description 等）

## 使用示例
用户说"杭州今天天气怎么样" → 调用天气工具，city="杭州", dayOffset=0
用户说"明天北京会下雨吗" → 调用天气工具，city="北京", dayOffset=1
用户说"下周上海天气" → 超出能力范围，告知用户仅支持3天预报
